# Funciones cuadráticas · Universidad Nueva Granada

Página de práctica de Matemáticas Básicas con **30 competencias** sobre:

- Evalúa funciones cuadráticas
- Vértice, eje de simetría y concavidad
- Ceros, raíces y discriminante
- Dominio, rango y aplicaciones

Abre `index.html` en cualquier navegador. No requiere instalación ni servidor.

## Funcionalidades

- Buscador de competencias.
- Pregunta de ejemplo al pasar el cursor.
- Práctica con respuestas aleatorias y retroalimentación.
- Gráficas SVG de parábolas con vértice y ceros.
- Puntuación guardada en `localStorage`.
- Resumen de fórmulas: forma general, vértice, forma vértice, discriminante y fórmula general.
